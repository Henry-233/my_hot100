## 题目描述
有 n 个航班（编号 1 到 n），bookings[i] = [first, last, seats]
表示在 [first, last] 区间每个航班预订 seats 个座位。
返回每个航班的总预订座位数。

## 解题思路
差分数组应用题。航班编号从 1 开始，需转为 0-based 索引：
`i = first - 1`, `j = last - 1`。
初始全 0 数组，对每个 booking 区间加 seats，最后还原。

## 关键代码
```python
def corpFlightBookings(bookings, n):
    nums = [0] * n
    df = Difference(nums)
    for first, last, seats in bookings:
        df.increment(first - 1, last - 1, seats)
    return df.result()
```

## 复杂度
- 时间：O(n + len(bookings))
- 空间：O(n)
