## 题目描述
给定二维矩阵 matrix，实现 NumMatrix 类，支持多次调用
sumRegion(row1, col1, row2, col2) 返回子矩阵的元素和。矩阵不可变。

## 解题思路
二维前缀和。preSum[i][j] = 以 (0,0) 为左上角、(i-1,j-1) 为右下角的矩形和。
子矩阵和用容斥原理：大矩阵 − 上边 − 左边 + 左上角。

## 关键代码
```python
class NumMatrix:
    def __init__(self, matrix):
        m, n = len(matrix), len(matrix[0])
        self.pre = [[0] * (n + 1) for _ in range(m + 1)]
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                self.pre[i][j] = (self.pre[i-1][j] + self.pre[i][j-1]
                                + matrix[i-1][j-1] - self.pre[i-1][j-1])

    def sumRegion(self, r1, c1, r2, c2):
        return (self.pre[r2+1][c2+1] - self.pre[r1][c2+1]
              - self.pre[r2+1][c1] + self.pre[r1][c1])
```

## 复杂度
- 时间：构造 O(m×n)，查询 O(1)
- 空间：O(m×n)
