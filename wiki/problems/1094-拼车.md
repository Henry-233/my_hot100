## 题目描述
trips[i] = [numPassengers, from, to] 表示 from 站上客、to 站下客。
车容量 capacity。判断能否在不超载的情况下完成所有行程。

## 解题思路
乘客在车上的区间是 `[from, to-1]`（to 时刻已下车）。
对每个 trip 给 `[from, to-1]` 区间加 numPassengers。
最后检查 result 数组中每个位置是否超过 capacity。
车站最多 1000 个，差分数组长度设为 1001。

## 关键代码
```python
def carPooling(trips, capacity):
    nums = [0] * 1001  # 最多 1000 个车站
    df = Difference(nums)
    for num, from_, to in trips:
        df.increment(from_, to - 1, num)  # to 时已下车
    res = df.result()
    return all(x <= capacity for x in res)
```

## 复杂度
- 时间：O(1000 + len(trips)) → O(max(n, trips))
- 空间：O(1000) → O(n)
