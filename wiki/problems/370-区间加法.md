## 题目描述
给定一个初始全 0 的长度为 `length` 的数组，以及多个三元组更新操作
`[start, end, inc]`，表示对 `[start, end]` 区间每个元素加 `inc`。
返回所有操作后的最终数组。（LeetCode 会员题）

## 解题思路
差分数组裸题。构造 Difference 类，遍历 updates 逐个 increment，
最后返回 result。

## 关键代码
```python
def getModifiedArray(length, updates):
    nums = [0] * length
    df = Difference(nums)
    for i, j, val in updates:
        df.increment(i, j, val)
    return df.result()
```

## 复杂度
- 时间：O(length + updates)
- 空间：O(length)
