## 适用场景
**栈**：后进先出场景 — 括号匹配、表达式求值、DFS 迭代版、
     单调栈（找下一个更大/更小元素）。
**队列**：先进先出场景 — BFS 辅助、滑动窗口最值（单调队列）、
        任务调度。

特征：看到"括号"、"下一个更大元素"、"表达式计算"、
"单调栈"、"滑动窗口最大值"、"用栈实现队列"。

## 代码模板
```python
# 单调栈 — 找下一个更大元素
def next_greater(nums):
    n = len(nums)
    res = [-1] * n
    stack = []
    for i in range(n):
        while stack and nums[stack[-1]] < nums[i]:
            idx = stack.pop()
            res[idx] = nums[i]
        stack.append(i)
    return res
```

```python
# 单调队列 — 滑动窗口最大值
from collections import deque

def max_sliding_window(nums, k):
    q = deque()
    res = []
    for i, x in enumerate(nums):
        # 移除越界元素
        if q and q[0] <= i - k:
            q.popleft()
        # 保持单调递减
        while q and nums[q[-1]] < x:
            q.pop()
        q.append(i)
        if i >= k - 1:
            res.append(nums[q[0]])
    return res
```

## 与相似模式的区别
- **链表**：栈/队列是抽象接口，可用数组或链表实现
- **DFS**：栈模拟递归实现 DFS，队列实现 BFS
- **堆**：堆用于动态取最值，单调栈/队列用于滑动窗口内的最值
