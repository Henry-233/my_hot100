## 适用场景
需要 O(1) 插入、删除、查找；去重；计数；两数之和类问题；
映射关系存储。
特征：看到"出现次数"、"是否存在"、"两数之和"、
"字母异位词"、"最长连续序列"、"重复元素"。

## 代码模板
```python
# 哈希表计数
from collections import Counter

def count_elements(nums):
    cnt = Counter(nums)
    # 或手动
    mp = {}
    for x in nums:
        mp[x] = mp.get(x, 0) + 1
    return mp
```

```python
# 哈希表 + 前缀和（和为 k 的子数组）
def subarray_sum(nums, k):
    mp = {0: 1}
    cur = res = 0
    for x in nums:
        cur += x
        res += mp.get(cur - k, 0)
        mp[cur] = mp.get(cur, 0) + 1
    return res
```

## 与相似模式的区别
- **字典树**：哈希用于精确字符串匹配，字典树用于前缀匹配
- **数组**：哈希是 key-value 结构，数组是索引-value 结构
- **堆**：哈希用于快速查找，堆用于快速获取最值
