## 适用场景
有序数组上的搜索、去重、两数之和、三数之和等问题。
特征：看到"有序数组"、"两数之和"、"三数之和"、"原地去重"、
"接雨水"、"盛水最多"。

## 代码模板
```python
# 左右指针（对撞指针）— 有序数组两数之和
def two_sum(nums, target):
    l, r = 0, len(nums) - 1
    while l < r:
        s = nums[l] + nums[r]
        if s == target:
            return [l, r]
        elif s < target:
            l += 1
        else:
            r -= 1
    return []
```

```python
# 快慢指针 — 原地去重
def remove_duplicates(nums):
    slow = 0
    for fast in range(1, len(nums)):
        if nums[fast] != nums[slow]:
            slow += 1
            nums[slow] = nums[fast]
    return slow + 1
```

## 与相似模式的区别
- **滑动窗口**：双指针维护的是一个区间满足某条件，滑动窗口通常维护一个可变长度窗口
- **链表双指针**：同思想，操作对象从数组变成链表
- **二分搜索**：双指针是 O(n) 线性扫描，二分是 O(log n) 折半
