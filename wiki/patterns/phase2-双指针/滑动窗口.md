## 适用场景
寻找满足某条件的最长/最短连续子数组或子串。
特征：看到"最长子串"、"最短子数组"、"无重复字符"、
"包含某条件的连续子数组"、"至多包含 k 个"。

## 代码模板
```python
# 不定长滑动窗口模板
def sliding_window(s):
    l = 0
    window = {}  # 窗口内状态
    res = 0
    for r in range(len(s)):
        # 扩大窗口
        window[s[r]] = window.get(s[r], 0) + 1

        # 收缩窗口（当条件不满足时）
        while not valid(window):
            window[s[l]] -= 1
            if window[s[l]] == 0:
                del window[s[l]]
            l += 1

        # 更新结果
        res = max(res, r - l + 1)
    return res
```

```python
# 固定长滑动窗口
def fixed_window(arr, k):
    cur = sum(arr[:k])
    res = cur
    for i in range(k, len(arr)):
        cur += arr[i] - arr[i - k]
        res = max(res, cur)
    return res
```

## 与相似模式的区别
- **数组双指针**：双指针关注两个位置的关系，滑动窗口关注整个窗口内的聚合状态
- **前缀和**：滑动窗口要求单调性（收缩条件明确），前缀和适用于任意数组
- **动态规划**：滑动窗口是贪心思路，一次扫描；DP 需要状态定义和转移
