## 适用场景
需要随机化选择、打乱、采样，或借助随机化降低最坏情况概率。
特征：看到"随机返回"、"打乱数组"、"等概率采样"、
"蓄水池抽样"、"随机化快排"。

## 代码模板
```python
import random

# Fisher-Yates 洗牌算法
def shuffle(nums):
    for i in range(len(nums) - 1, 0, -1):
        j = random.randint(0, i)
        nums[i], nums[j] = nums[j], nums[i]
    return nums

# 蓄水池抽样 — 从未知长度的流中均匀采样 k 个
def reservoir_sampling(stream, k):
    res = []
    for i, x in enumerate(stream):
        if i < k:
            res.append(x)
        else:
            j = random.randint(0, i)
            if j < k:
                res[j] = x
    return res
```
