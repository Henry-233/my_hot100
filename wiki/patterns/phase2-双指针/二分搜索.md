## 适用场景
在有序区间内查找满足某条件的边界值。
特征：看到"有序数组"、"查找目标值"、"搜索插入位置"、
"寻找峰值"、"旋转排序数组"、"最小化最大值"。

## 代码模板
```python
# 标准二分 — 查找 target
def binary_search(nums, target):
    l, r = 0, len(nums) - 1
    while l <= r:
        mid = l + (r - l) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            l = mid + 1
        else:
            r = mid - 1
    return -1
```

## 与相似模式的区别
- **数组双指针**：双指针 O(n)，二分 O(log n)；二分要求有序或单调性
- **分治算法**：二分是减治（每次丢弃一半），分治是分开处理再合并
- **动态规划**：二分答案用于"最小化最大值"类问题，DP 是该类问题的另一种思路
