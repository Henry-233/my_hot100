## 适用场景
链表上的定位、判环、找中点、倒数第 k 个节点等问题。
特征：看到"环形链表"、"倒数第 N 个节点"、"链表中点"、
"相交链表"、"回文链表"。

## 代码模板
```python
# 快慢指针 — 判环
def has_cycle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow == fast:
            return True
    return False

# 快慢指针 — 找环入口
def detect_cycle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow == fast:
            fast = head
            while slow != fast:
                slow = slow.next
                fast = fast.next
            return slow
    return None
```

```python
# 双指针 — 倒数第 k 个节点
def find_kth_from_end(head, k):
    fast = slow = head
    for _ in range(k):
        fast = fast.next
    while fast:
        slow = slow.next
        fast = fast.next
    return slow
```

## 与相似模式的区别
- **数组双指针**：同是双指针思想，链表通过 .next 移动，数组通过索引
- **递归**：链表天然适合递归（反转、合并），双指针是迭代解法
