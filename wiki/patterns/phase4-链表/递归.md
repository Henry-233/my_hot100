## 适用场景
问题可分解为相同结构的子问题；树/链表的天然递归结构；
回溯、分治、DFS 的基础。
特征：看到"反转链表"、"合并链表"、"树的前中后序遍历"、
"斐波那契"、"汉诺塔"、"子集/排列（回溯）"。

```python
# 示例：递归反转链表
def reverse_list(head):
    if not head or not head.next:
        return head
    new_head = reverse_list(head.next)
    head.next.next = head
    head.next = None
    return new_head
```

## 与相似模式的区别
- **迭代（栈模拟）**：递归隐式使用系统栈，迭代显式使用栈；递归代码简洁但有栈溢出风险
- **分治算法**：分治是递归的特殊形式（分→治→合）
- **动态规划**：递归自顶向下（记忆化搜索），DP 常自底向上填表
- **DFS**：DFS 是递归在图/树上的应用
