## 适用场景
二叉树的前序、中序、后序遍历；自顶向下或自底向上传递信息。
特征：看到"二叉树遍历"、"前/中/后序"、"二叉树的最大深度"、
"对称二叉树"、"路径和"、"直径"、"最近公共祖先"。

## 代码模板
```python
# 前序遍历（根左右）
def preorder(root):
    if not root:
        return
    process(root)              # 根
    preorder(root.left)        # 左
    preorder(root.right)       # 右

# 中序遍历（左根右）
def inorder(root):
    if not root:
        return
    inorder(root.left)
    process(root)
    inorder(root.right)

# 后序遍历（左右根）
def postorder(root):
    if not root:
        return
    postorder(root.left)
    postorder(root.right)
    process(root)
```

```python
# 自底向上（后序遍历模式）— 求深度/直径/平衡判断
def dfs(root):
    if not root:
        return 0  # 空节点返回值
    left = dfs(root.left)
    right = dfs(root.right)
    # 合并左右子树信息
    return 1 + max(left, right)
```

## 与相似模式的区别
- **层序遍历**：递归遍历是 DFS（深度优先），层序遍历是 BFS（广度优先）
- **DFS**：递归遍历是 DFS 在二叉树上的具体形式
- **迭代遍历**：用栈模拟递归，适合避免栈溢出或需要控制遍历过程
