## 适用场景
每步选择当前局部最优即能得到全局最优；问题具有贪心选择性质。
特征：看到"跳跃游戏"、"加油站"、"分发糖果"、"会议室"、
"任务调度"、"根据身高重建队列"。

## 代码模板
```python
# 贪心通用思路
def greedy(items):
    items.sort(key=lambda x: x.end)  # 按某维度排序
    res = 0
    cur_end = float('-inf')
    for item in items:
        if item.start >= cur_end:  # 贪心选择条件
            res += 1
            cur_end = item.end
    return res
```

```python
# 跳跃游戏 — 贪心
def can_jump(nums):
    farthest = 0
    for i, n in enumerate(nums):
        if i > farthest:  # 当前位置不可达
            return False
        farthest = max(farthest, i + n)
    return farthest >= len(nums) - 1
```

## 与相似模式的区别
- **动态规划**：每步贪心不可逆，DP 通过状态转移考虑所有可能；能用贪心的问题也能用 DP，但贪心更快
- **堆**：贪心常配合堆实现（如任务调度、合并 K 个有序序列）
- **回溯法**：贪心只走一条路径，回溯穷举所有路径
