## 适用场景
需要穷举所有可能的解（组合、排列、子集、棋盘等），
搜索空间可表示为决策树。
特征：看到"所有可能的组合"、"全排列"、"子集"、
"N 皇后"、"电话号码"、"括号生成"、"单词搜索"、"分割回文串"。

## 代码模板
```python
# 回溯通用模板
def backtrack(path, choices, start):
    if 满足结束条件:
        res.append(path[:])
        return

    for i in range(start, len(choices)):
        if not valid(choices[i]):
            continue        # 剪枝
        path.append(choices[i])      # 做出选择
        backtrack(path, choices, i + 1)  # 递归（组合用 i+1，排列不用）
        path.pop()                    # 撤销选择
```

```python
# 全排列（不含重复元素）
def permute(nums):
    res = []
    def backtrack(path, used):
        if len(path) == len(nums):
            res.append(path[:])
            return
        for i in range(len(nums)):
            if used[i]:
                continue
            used[i] = True
            path.append(nums[i])
            backtrack(path, used)
            path.pop()
            used[i] = False
    backtrack([], [False] * len(nums))
    return res
```

## 与相似模式的区别
- **DFS**：回溯 = 决策树上的 DFS + 撤销选择；DFS 更通用
- **动态规划**：回溯穷举所有解（可能重复子问题），DP 利用最优子结构避免重复
- **分治算法**：分治将问题拆分后独立求解再合并，回溯在搜索树上走路径
