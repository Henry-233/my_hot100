## 适用场景
无权图的最短路径；逐层扩散搜索；需要按距离处理的问题。
特征：看到"最短路径（无权）"、"最少步数"、"层序遍历"、

## 代码模板
```python
from collections import deque

# 标准 BFS（图）
def bfs(graph, start):
    visited = set([start])
    q = deque([start])
    while q:
        node = q.popleft()
        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                q.append(neighbor)
    return visited
```

```python
# BFS 求最短路径（带步数）
def bfs_shortest_path(graph, start, target):
    q = deque([(start, 0)])  # (节点, 步数)
    visited = set([start])
    while q:
        node, steps = q.popleft()
        if node == target:
            return steps
        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                q.append((neighbor, steps + 1))
    return -1
```

# 双向 BFS（优化版）
def bidirectional_bfs(start, target):
    q1, q2 = set([start]), set([target])
    steps = 0
    while q1 and q2:
        if len(q1) > len(q2):
            q1, q2 = q2, q1  # 每次扩展较小的集合

## 与相似模式的区别
- **DFS**：BFS 找最短路径（无权图），DFS 找任意路径/判连通性
- **层序遍历**：层序遍历 = BFS 在二叉树上的应用
- **最短路径（Dijkstra）**：BFS 处理无权图，Dijkstra 处理带权图
