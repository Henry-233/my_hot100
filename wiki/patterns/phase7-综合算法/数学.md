## 适用场景
利用数学性质、公式、位运算技巧直接求解问题。
特征：看到"只出现一次的数字"、"多数元素（摩尔投票）"、
"快速幂"、"最大公约数"、"质数"、"位运算"、"n! 后的零"。

## 代码模板
```python
# 快速幂（二分幂）
def quick_pow(x, n):
    res = 1.0
    if n < 0:
        x = 1 / x
        n = -n
    while n:
        if n & 1:
            res *= x
        x *= x
        n >>= 1
    return res
```

```python
# 位运算技巧
# 判断奇偶: n & 1
# 除以2: n >> 1
# 乘以2: n << 1
# 交换: a ^= b; b ^= a; a ^= b
# 最低位1: n & -n
# 消去最低位1: n & (n - 1)

# 只出现一次的数字（其他出现两次）
def single_number(nums):
    res = 0
    for x in nums:
        res ^= x
    return res
```

```python
# 摩尔投票 — 多数元素
def majority_element(nums):
    candidate = count = 0
    for x in nums:
        if count == 0:
            candidate = x
        count += 1 if x == candidate else -1
    return candidate
```

## 与相似模式的区别
- **动态规划**：数学解法通常 O(1) 或 O(n) 直接得解，DP 需要状态转移
- **位运算**（子模式）：利用位操作的低级特性
- **贪心算法**：摩尔投票等数学方法本质也是一种贪心
