问题具有最优子结构和重叠子问题；求最值、计数、可行性。

## 代码模板
```python
# DP 五步法：
# 1. 定义 dp[i] 或 dp[i][j] 的含义
# 2. 推导状态转移方程
# 3. 确定初始条件（base case）
# 4. 确定遍历顺序
# 5. 举例验证（可选）

# 示例：01 背包
def knapsack(weights, values, capacity):
    n = len(weights)
    dp = [0] * (capacity + 1)
    for i in range(n):
        for w in range(capacity, weights[i] - 1, -1):
            dp[w] = max(dp[w], dp[w - weights[i]] + values[i])
    return dp[capacity]
```

```python
# 线性 DP — 最长递增子序列
def length_of_lis(nums):
    dp = [1] * len(nums)
    for i in range(len(nums)):
        for j in range(i):
            if nums[j] < nums[i]:
                dp[i] = max(dp[i], dp[j] + 1)
    return max(dp)
```

```python
# 二维 DP — 编辑距离
def edit_distance(word1, word2):
    m, n = len(word1), len(word2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(m + 1):
        dp[i][0] = i
    for j in range(n + 1):
        dp[0][j] = j
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if word1[i-1] == word2[j-1]:
                dp[i][j] = dp[i-1][j-1]
            else:
                dp[i][j] = 1 + min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1])
    return dp[m][n]
```

## 与相似模式的区别
- **贪心算法**：DP 考虑全局最优，贪心每步选局部最优（不一定全局优）
- **分治算法**：DP 子问题重叠，分治子问题独立
- **回溯法**：DP 利用重叠子问题剪枝，回溯穷举所有可能
- **记忆化搜索（递归+缓存）**：自顶向下 DP，填表是自底向上 DP
