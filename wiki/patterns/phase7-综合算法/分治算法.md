## 适用场景
问题可分解为互不相交的同类子问题，子问题独立求解后再合并。
特征：看到"归并排序"、"快速排序"、"数组中的第 K 大元素（快速选择）"、
"排序链表"、"为运算表达式设计优先级"。

## 代码模板
```python
# 归并排序 — 分治经典
def merge_sort(nums):
    if len(nums) <= 1:
        return nums
    mid = len(nums) // 2
    left = merge_sort(nums[:mid])   # 分
    right = merge_sort(nums[mid:])  # 分
    return merge(left, right)       # 治 + 合

def merge(a, b):
    res = []
    i = j = 0
    while i < len(a) and j < len(b):
        if a[i] < b[j]:
            res.append(a[i]); i += 1
        else:
            res.append(b[j]); j += 1
    res.extend(a[i:])
    res.extend(b[j:])
    return res
```

```python
# 快速选择 — 第 K 大（分治 + 减治）
def find_kth_largest(nums, k):
    def partition(l, r):
        pivot = nums[r]
        i = l
        for j in range(l, r):
            if nums[j] >= pivot:  # 大的放左边
                nums[i], nums[j] = nums[j], nums[i]
                i += 1
        nums[i], nums[r] = nums[r], nums[i]
        return i

    l, r = 0, len(nums) - 1
    target = k - 1
    while True:
        p = partition(l, r)
        if p == target:
            return nums[p]
        elif p < target:
            l = p + 1
        else:
            r = p - 1
```

## 与相似模式的区别
- **动态规划**：分治的子问题独立，DP 的子问题有重叠
- **回溯法**：分治拆分后独立求解合并，回溯在搜索树上走路径并撤销
- **递归**：分治是递归的特殊形式，强调分+治+合三步
