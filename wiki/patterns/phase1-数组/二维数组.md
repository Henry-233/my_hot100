## 代码模板
```python
# 二维前缀和
def build_2d_prefix(matrix):
    m, n = len(matrix), len(matrix[0])
    pre = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(m):
        for j in range(n):
            pre[i + 1][j + 1] = (pre[i + 1][j] + pre[i][j + 1]
                                 - pre[i][j] + matrix[i][j])
    return pre

# 查询子矩阵和 (r1,c1) 到 (r2,c2)
def sum_region(pre, r1, c1, r2, c2):
    return (pre[r2 + 1][c2 + 1] - pre[r1][c2 + 1]
            - pre[r2 + 1][c1] + pre[r1][c1])
```

```python
# 矩阵螺旋遍历
def spiral_order(matrix):
    res = []
    while matrix:
        res += matrix.pop(0)              # 上
        if matrix and matrix[0]:
            for row in matrix:
                res.append(row.pop())     # 右
        if matrix:
            res += matrix.pop()[::-1]     # 下
        if matrix and matrix[0]:
            for row in matrix[::-1]:
                res.append(row.pop(0))    # 左
    return res
```

## 与相似模式的区别
- **图**：二维数组是图的邻接矩阵特例，图有更一般的表示（邻接表）
- **DFS/BFS**：二维矩阵的遍历常用 DFS/BFS（如岛屿问题），但矩阵本身是数据结构
