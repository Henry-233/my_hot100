## 适用场景
需要频繁查询数组区间和（或区间内满足某条件的统计值），
且数组在查询之间不变（静态数组）。
特征：看到"子数组和"、"区间和"、"区域检索"、"连续子数组"。

核心原理：`preSum[i]` 记录 `nums[0..i-1]` 的累加和，
则区间 `[i, j]` 的和 = `preSum[j+1] - preSum[i]`，O(1) 完成查询。

局限性：
- 原数组不能变化（元素修改后 preSum 全部失效）
- 只适用于存在逆运算的场景（+ ↔ −, × ↔ ÷），max/min 等没有逆运算

## 代码模板

### 一维前缀和（类封装版）
```python
class NumArray:
    def __init__(self, nums):
        # preSum[i] = sum(nums[0..i-1])
        self.preSum = [0] * (len(nums) + 1)
        for i in range(1, len(self.preSum)):
            self.preSum[i] = self.preSum[i - 1] + nums[i - 1]

    # 查询闭区间 [left, right] 的和
    def sumRange(self, left, right):
        return self.preSum[right + 1] - self.preSum[left]
```

### 二维前缀和
```python
class NumMatrix:
    def __init__(self, matrix):
        m, n = len(matrix), len(matrix[0])
        # preSum[i][j] = 以 (0,0) 为左上角、(i-1,j-1) 为右下角的矩阵和
        self.preSum = [[0] * (n + 1) for _ in range(m + 1)]
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                self.preSum[i][j] = (self.preSum[i - 1][j]
                    + self.preSum[i][j - 1]
                    + matrix[i - 1][j - 1]
                    - self.preSum[i - 1][j - 1])

    # 查询子矩阵 (r1,c1) 到 (r2,c2) 的和
    def sumRegion(self, r1, c1, r2, c2):
        return (self.preSum[r2 + 1][c2 + 1]
              - self.preSum[r1][c2 + 1]
              - self.preSum[r2 + 1][c1]
              + self.preSum[r1][c1])
```

### 前缀和 + 哈希表（和为 k 的子数组计数）
```python
def subarraySum(nums, k):
    count = cur = 0
    mp = {0: 1}
    for x in nums:
        cur += x
        count += mp.get(cur - k, 0)
        mp[cur] = mp.get(cur, 0) + 1
    return count
```

**记忆要点**：
- 一维：`preSum` 长度 n+1，`preSum[0]=0` 方便处理从头开始的区间
- 二维：子矩阵和 = 大矩阵 − 上边 − 左边 + 左上角（容斥原理）

## 与相似模式的区别
- **差分数组**：前缀和查询区间和，差分修改区间值，两者互逆
- **滑动窗口**：前缀和适用于任意子数组（含负数），滑动窗口要求单调性
- **动态规划**：前缀和是预处理技巧，DP 是状态转移，前缀和常作为 DP 的优化手段
- **线段树**：前缀和只能离线静态查询，线段树支持动态修改 + 查询
