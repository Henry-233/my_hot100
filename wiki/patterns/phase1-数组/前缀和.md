## 适用场景
需要频繁查询数组区间和（或区间内满足某条件的统计值），
且数组在查询之间不变（静态数组）。
特征：看到"子数组和"、"区间和"、"连续子数组"。

## 代码模板
```python
# 一维前缀和
def build_prefix_sum(nums):
    n = len(nums)
    prefix = [0] * (n + 1)
    for i in range(n):
        prefix[i + 1] = prefix[i] + nums[i]
    return prefix

# 查询区间 [l, r] 的和
def range_sum(prefix, l, r):
    return prefix[r + 1] - prefix[l]
```

```python
# 前缀和 + 哈希表（找和为 k 的子数组个数）
def subarray_sum(nums, k):
    count = cur_sum = 0
    mp = {0: 1}
    for x in nums:
        cur_sum += x
        count += mp.get(cur_sum - k, 0)
        mp[cur_sum] = mp.get(cur_sum, 0) + 1
    return count
```

## 与相似模式的区别
- **差分数组**：差分处理区间修改，前缀和处理区间查询，两者互为逆运算
- **滑动窗口**：前缀和适用于任意子数组（含负数），滑动窗口要求单调性
- **动态规划**：前缀和是预处理技巧，DP 是状态转移，前缀和常作为 DP 的优化手段
