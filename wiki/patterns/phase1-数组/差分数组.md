## 适用场景
需要对数组进行多次区间增减操作，最后查询最终数组。
特征：看到"多次区间加/减"、"区间修改"、"航班预订"、"拼车"。

核心原理：`diff[i] += val` 表示 `nums[i..]` 全部 +val，
`diff[j+1] -= val` 表示 `nums[j+1..]` 全部 -val，
合起来就是对 `[i, j]` 区间 +val，O(1) 完成一次区间修改。

## 代码模板
```python
# 差分数组工具类
class Difference:
    def __init__(self, nums):
        assert len(nums) > 0
        self.diff = [0] * len(nums)
        self.diff[0] = nums[0]
        for i in range(1, len(nums)):
            self.diff[i] = nums[i] - nums[i - 1]

    # 给闭区间 [i, j] 增加 val（可以是负数）
    def increment(self, i, j, val):
        self.diff[i] += val
        if j + 1 < len(self.diff):      # j+1 越界则是对后续全部生效
            self.diff[j + 1] -= val

    # 还原结果数组
    def result(self):
        res = [0] * len(self.diff)
        res[0] = self.diff[0]
        for i in range(1, len(self.diff)):
            res[i] = res[i - 1] + self.diff[i]
        return res
```

**使用模式**：
1. 初始化 `nums = [0] * length`（全零数组）
2. 构造 `Difference(nums)`
3. 对每个操作 `(i, j, val)` 调用 `df.increment(i, j, val)`
4. 调用 `df.result()` 获取最终数组

**易错点**：
- 航班编号从 1 开始 → 索引要减 1：`i = booking[0] - 1`
- 拼车中乘客在 `[from, to-1]` 区间在车上（`to` 时刻已下车）

## 与相似模式的区别
- **前缀和**：前缀和查询区间和，差分修改区间值，两者互逆
- **线段树/树状数组**：差分处理离线批量修改（全部操作完再查询），线段树处理在线修改+查询混合
- **滑动窗口**：差分是"批量修改后一次查询"，滑动窗口是"边移动边查询"
