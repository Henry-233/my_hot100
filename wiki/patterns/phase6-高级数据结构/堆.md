## 适用场景
需要动态获取最大/最小值；Top K 问题；合并 K 个有序序列；
Dijkstra 算法中的优先队列。
特征：看到"第 K 大/小"、"Top K"、"合并 K 个链表"、
"数据流中位数"、"任务调度"、"频率排序"。

## 代码模板
```python
import heapq

# 小顶堆 — Top K 大
def top_k_largest(nums, k):
    heap = []
    for x in nums:
        heapq.heappush(heap, x)
        if len(heap) > k:
            heapq.heappop(heap)
    return heap

# 大顶堆 — Top K 小（取负入堆）
def top_k_smallest(nums, k):
    heap = []
    for x in nums:
        heapq.heappush(heap, -x)
        if len(heap) > k:
            heapq.heappop(heap)
    return [-x for x in heap]
```

```python
# 数据流中位数（双堆法）
class MedianFinder:
    def __init__(self):
        self.small = []  # 大顶堆（存较小的一半，取负）
        self.large = []  # 小顶堆（存较大的一半）

    def add_num(self, num):
        heapq.heappush(self.small, -num)
        heapq.heappush(self.large, -heapq.heappop(self.small))
        if len(self.large) > len(self.small):
            heapq.heappush(self.small, -heapq.heappop(self.large))
```

## 与相似模式的区别
- **二叉搜索树**：BST 全序、支持范围查询，堆只保证堆顶最值
- **单调栈/队列**：单调结构找邻近的最值，堆找全局动态最值
- **排序**：排序 O(n log n) 后取 Top K，堆 O(n log K)
