## 代码模板
```python
# 邻接表建图
def build_graph(n, edges):
    graph = [[] for _ in range(n)]
    for u, v, w in edges:  # w 为权重（无权图省略）
        graph[u].append((v, w))
        # 无向图加双向
        # graph[v].append((u, w))
    return graph
```

```python
# 拓扑排序（Kahn 算法 / BFS）
from collections import deque

def topo_sort(n, prerequisites):
    graph = [[] for _ in range(n)]
    indegree = [0] * n
    for course, prereq in prerequisites:
        graph[prereq].append(course)
        indegree[course] += 1
    q = deque([i for i in range(n) if indegree[i] == 0])
    order = []
    while q:
        node = q.popleft()
        order.append(node)
        for neighbor in graph[node]:
            indegree[neighbor] -= 1
            if indegree[neighbor] == 0:
                q.append(neighbor)
    return order if len(order) == n else []
```

## 与相似模式的区别
- **树**：树是图的特例（无环连通图），树有层级，图更通用
- **二维数组**：二维网格是图的邻接矩阵表示
- **DFS/BFS**：图上的遍历算法，图是数据结构
