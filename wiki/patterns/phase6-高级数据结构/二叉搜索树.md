## 适用场景
需要动态维护有序集合，支持快速查找、插入、删除；
利用 BST 中序遍历有序的性质。
特征：看到"二叉搜索树"、"BST"、"验证 BST"、"BST 中第 k 小"、
"有序链表/数组转 BST"、"BST 的插入/删除"。

## 代码模板
```python
# 验证 BST（利用中序遍历递增）
def is_valid_bst(root):
    prev = float('-inf')
    def inorder(node):
        nonlocal prev
        if not node:
            return True
        if not inorder(node.left):
            return False
        if node.val <= prev:
            return False
        prev = node.val
        return inorder(node.right)
    return inorder(root)
```

```python
# BST 搜索
def search_bst(root, val):
    if not root or root.val == val:
        return root
    if val < root.val:
        return search_bst(root.left, val)
    return search_bst(root.right, val)
```

## 与相似模式的区别
- **堆**：BST 支持有序遍历和范围查询，堆只保证堆顶最值
- **哈希**：BST 有序、O(log n)，哈希无序、O(1)
- **递归遍历**：BST 的中序遍历产生有序序列
