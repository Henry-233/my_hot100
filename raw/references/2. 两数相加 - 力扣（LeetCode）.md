## 方法一：递归

把虚线内要计算的内容，可以理解为一个和原问题相似的，规模更小的子问题，所以非常适合用 **递归** 解决。

每次把两个节点值 与进位值 相加，除以 的余数即为当前节点需要保存的数位，除以 的商即为新的进位值。

一遇到递归就头晕？请看 [【基础算法精讲 09】](https://leetcode.cn/link/?target=https%3A%2F%2Fwww.bilibili.com%2Fvideo%2FBV1UD4y1Y769%2F) 。

不了解链表的同学请看 [【基础算法精讲 06】](https://leetcode.cn/link/?target=https%3A%2F%2Fwww.bilibili.com%2Fvideo%2FBV1sd4y1x7KN%2F) 。

### 写法一：创建新节点

```
class Solution:
    # l1 和 l2 为当前遍历的节点，carry 为进位
    def addTwoNumbers(self, l1: Optional[ListNode], l2: Optional[ListNode], carry=0) -> Optional[ListNode]:
        if l1 is None and l2 is None and carry == 0:  # 递归边界
            return None

        s = carry
        if l1:
            s += l1.val  # 累加进位与节点值
            l1 = l1.next
        if l2:
            s += l2.val
            l2 = l2.next

        # s 除以 10 的余数为当前节点值，商为进位
        return ListNode(s % 10, self.addTwoNumbers(l1, l2, s // 10))
```

### 写法二：原地修改

代码实现时，有一个简化代码的小技巧：如果递归中发现 的长度比 更长，那么可以交换 和 ，保证 不是空节点，从而简化代码逻辑。

```
class Solution:
    # l1 和 l2 为当前遍历的节点，carry 为进位
    def addTwoNumbers(self, l1: Optional[ListNode], l2: Optional[ListNode], carry=0) -> Optional[ListNode]:
        if l1 is None and l2 is None:  # 递归边界
            return ListNode(carry) if carry else None  # 如果进位了，就额外创建一个节点
        if l1 is None:  # 如果 l1 是空的，那么此时 l2 一定不是空节点
            l1, l2 = l2, l1  # 交换 l1 与 l2，保证 l1 非空，从而简化代码
        s = carry + l1.val + (l2.val if l2 else 0)  # 节点值和进位加在一起
        l1.val = s % 10  # 每个节点保存一个数位（直接修改原链表）
        l1.next = self.addTwoNumbers(l1.next, l2.next if l2 else None, s // 10)  # 进位
        return l1
```

## 方法二：迭代

首先请看如何遍历一个链表，代码框架如下：

```
# 遍历链表 l1
while l1:  # 从链表头节点开始向后遍历，直到遇到空节点
    print(l1.val)  # 当前节点值
    l1 = l1.next  # 准备遍历下一个节点
```

迭代的思路是，初始化答案为一个「空链表」，每次循环，向该链表末尾添加一个节点（保存一个数位）。

循环即遍历链表 和 ，每次把两个节点值 与进位值 相加，除以 的余数即为当前节点需要保存的数位，除以 的商即为新的进位值。

需要注意的是，在第一次循环时，我们无法往一个空节点的末尾添加节点。这里的技巧是，创建一个 **哨兵节点** （dummy node），当成初始的「空链表」。循环结束后，哨兵节点的下一个节点就是最终要返回的链表头节点。

```
class Solution:
    def addTwoNumbers(self, l1: Optional[ListNode], l2: Optional[ListNode]) -> Optional[ListNode]:
        cur = dummy = ListNode()  # 哨兵节点
        carry = 0  # 进位值
        while l1 or l2 or carry:  # 有一个不是空节点，或者还有进位，就继续迭代
            s = carry
            if l1:
                s += l1.val  # 节点值和进位加在一起
                l1 = l1.next  # 下一个节点
            if l2:
                s += l2.val  # 节点值和进位加在一起
                l2 = l2.next  # 下一个节点
            cur.next = ListNode(s % 10)  # 每个节点保存一个数位
            carry = s // 10  # 新的进位
            cur = cur.next  # 下一个节点
        return dummy.next  # 哨兵节点的下一个节点就是头节点
```

让ai帮我写了一个新手友好的写法，将carry的进位以及求和职能拆分了  
这版代码里，最关键的变量是 dummy、tail、current\_sum、carry\_next。这四个名字如果你都能真正理解，这题以后就很难再断片。

dummy  
它是结果链表前面的“占位头节点”。它自己不存真正答案，只负责帮我们稳稳守住结果链表的入口。因为链表在构造时，尾指针会一直往后走，如果没有 dummy，后面可能找不到真正的头节点。  
tail  
它始终指向结果链表当前最后一个节点。你可以把它理解成“施工现场最后一个已经搭好的位置”，每次新节点造出来，就接到 tail 后面，然后 tail 再往后走。  
current\_sum  
这个名字表示“当前这一位总共加出来多少”。比如这一轮要处理的是 4 + 6 + 1，那么 current\_sum = 11。它只负责这一轮，不负责下一轮。  
carry\_next  
这个名字表示“这一轮算完后，要交给下一轮的进位”。比如 11 // 10 = 1，这个 1 就是下一轮要带着继续加的值。  
这个命名的好处是：你一看到它，就知道它不是“当前总和”，而是“下一轮要用的进位”。这比把一个变量同时拿来表示“当前和”和“进位”更容易记忆，也更适合复习时记忆：

```python
class Solution:
    def addTwoNumbers(self, l1: Optional[ListNode], l2: Optional[ListNode]) -> Optional[ListNode]:
        # 【步骤1】先创建一个哨兵节点 dummy
        # 它的作用不是存答案，而是“帮我们稳稳记住结果链表的头”
        # 因为链表题里，一边构造一边往后移动指针时，很容易把真正的头节点弄丢
        dummy = ListNode()

        # 【步骤2】tail 表示结果链表当前的“尾巴”
        # 一开始结果链表还没有真正的数字节点，所以 tail 先指向 dummy
        tail = dummy

        # 【步骤3】carry_next 记录“这一轮算完后，要交给下一轮的进位”
        # 比如这一轮算出 13，那么当前位留下 3，下一轮要带着 1 继续算
        carry_next = 0

        # 【步骤4】循环什么时候继续？
        # 只要下面三种情况有一种还存在，就不能停：
        # 1）l1 还有节点没处理完
        # 2）l2 还有节点没处理完
        # 3）上一轮留下来的进位 carry_next 还没处理完
        # ⚠️ 注意：这里一定要用 or，不能用 and
        while l1 or l2 or carry_next:
            # 【步骤5】current_sum 表示“当前这一位的总和”
            # 一开始，先把上一轮留下来的进位放进来
            current_sum = carry_next

            # 【步骤6】如果 l1 当前还有节点，就把它的值加到 current_sum 里
            if l1:
                current_sum += l1.val
                # 处理完当前节点后，l1 往后走一步
                l1 = l1.next

            # 【步骤7】如果 l2 当前还有节点，也把它的值加到 current_sum 里
            if l2:
                current_sum += l2.val
                # 处理完当前节点后，l2 往后走一步
                l2 = l2.next

            # 【步骤8】当前这一位应该留下“个位数”
            # 比如 current_sum = 17，那么这一位存 7
            digit = current_sum % 10

            # 【步骤9】把这一位数字接到结果链表后面
            tail.next = ListNode(digit)

            # 【步骤10】把“十位部分”作为下一轮的进位
            # 比如 current_sum = 17，那么下一轮要带 1 过去
            carry_next = current_sum // 10

            # 【步骤11】tail 往后移动到新接上的节点
            # 这样下一轮才能继续往后接
            tail = tail.next

        # 【步骤12】dummy 本身只是占位，不是答案的一部分
        # 真正的结果链表头节点是 dummy.next
        return dummy.next
```

def addTwoNumbers(self, l1: Optional[ListNode], l2: Optional[ListNode]) -> Optional[ListNode]:
        head = tail = ListNode()     # 尾插法
        add = 0 
        while l1 and l2:             # 都存在就以l2原地合并
            l2.val += l1.val + add
            add = l2.val // 10
            l2.val %= 10
            tail.next = l2
            tail = l2
            l1, l2 = l1.next, l2.next
        tail.next = l2 if l2 else l1 # 合并剩余部分

            return head.next

            if tail.next.val < 10:
                return head.next
            tail.next.val %= 10
            tail = tail.next

class Solution {
public:
    ListNode* addTwoNumbers(ListNode* &l1, ListNode* &l2) {
        ListNode* head = l1;
        uint dig=0,carry=0;
        while(carry || l1 || l2){
            int v1 = l1?l1->val:0;
            int v2 = l2?l2->val:0;
            dig = v1+v2+carry;
            carry=dig/10;
            dig%=10;
            l1->val = dig;
            if(l1->next==nullptr && (carry || (l2 && l2->next))){
                l1->next=new ListNode(0);
            }
            l1 = l1->next;
            if(l2)l2 = l2->next;
        }
        return head;
    }
};
